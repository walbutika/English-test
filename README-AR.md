# English Star — موقع للآيفون

## الرفع على GitHub (من التليفون)
1. اعمل مستودع جديد (New repository) باسم مثلاً `english-star` وخليه **Public**.
2. **Add file → Upload files** وارفع كل الملفات اللي في الـ zip مع بعض.
3. **Commit changes**.
4. من **Settings → Pages**: في Source اختار **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، و**Save**.
5. استنى دقيقة أو دقيقتين، الرابط يطلع فوق: `https://اسمك.github.io/english-star/`

## على الآيفون
افتح الرابط في **Safari** ← زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.
يشتغل زي التطبيق، ويحفظ النجوم والنتايج، ويشتغل حتى بدون نت بعد أول فتحة.

## التحديث
ارفع `index.html` الجديد (و`sw.js` لو تغيّر) بنفس الطريقة، وسكّر اللعبة وافتحها من جديد.

ملاحظة: الصوت هو صوت الآيفون الإنجليزي. لو الصوت ما طلعش، تأكد إن زر الصامت مطفي.
